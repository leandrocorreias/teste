## 4. Como publicar daqui para frente

O repositório tem o `.cpanel.yml` pronto. No cPanel da conta `cadilla12321`:

**Git™ Version Control → Create → Clone a Repository**
`https://github.com/leandrocorreias/teste.git` → **Manage → Pull or Deploy → Update from
Remote → Deploy HEAD Commit**

O deploy copia a pasta construída para o `public_html`, **apaga as pastas antigas antes**
(senão página excluída continua no ar) e reescreve o `.htaccess` para a raiz. A `master`
já está com todo o trabalho, então não precisa trocar de branch.

Da segunda vez em diante: eu empurro, você clica em *Deploy*.

**Se preferir o zip:** antes de extrair, apague `projetos/`, `eventos/connect-heroes/` e
`eventos/mr-moo-festival/` — o upload não remove nada sozinho.
